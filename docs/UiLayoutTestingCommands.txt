TAssist refresh-ui-layout manual testing

Use Java 25 with JavaFX and a desktop session.
In a checkout containing this local branch, preserve unrelated work before switching:

git switch refresh-ui-layout
./gradlew check coverage
./gradlew -I config/ui-layout-demo.gradle run

On Linux, prefix automated checks with xvfb-run.
The launcher stores data/preferences in _temp/refresh-ui-layout/session/.
Enter application commands ONE LINE AT A TIME, pressing Enter except for DRAFTS.
The setup clear deletes only this isolated session's data.
Detailed instructions: docs/UiLayoutTesting.md

1. SETUP - EXECUTE EACH LINE
clear
addclass m/CS2103 c/F10
addclass m/CS2103 c/F11
addclass m/CS2101 c/TUTORIAL-GROUP-WITH-A-LONG-NAME
add sn/DEMO0001 n/Alice Tan With A Long Student Name e/alice.with.a.long.email.address@example.com tg/alice_demo t/tutorial t/project
add sn/DEMO0002 n/Ben Lim e/ben@example.com tg/ben_demo t/project
add sn/DEMO0003 n/Cara Ng e/cara@example.com t/tutorial
assign sn/DEMO0001 m/CS2103 c/F10
assign sn/DEMO0002 m/CS2103 c/F10
assign sn/DEMO0003 m/CS2103 c/F11
assign sn/DEMO0001 m/CS2101 c/TUTORIAL-GROUP-WITH-A-LONG-NAME

EXPECT: input and output remain at top. Lower split: classes left, students right.
Class indices 1-3; module codes/names and membership counts 2, 1, 1.
Students alphabetical: Alice, Ben, Cara. Footer shows the isolated save location.
Drag divider both ways; classes initially get about 45% width. Scroll both lists.
Resize wide, 740 px, then existing 450 px minimum. Long names, email and tags wrap.
Cara has no blank Telegram line. Class clicks leave data/output and styling unchanged.

Other classes' counts stay 1.
