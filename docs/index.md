# TAssist

[![CI Status](https://github.com/AY2627S1-CS2103-F10-2/tp/actions/workflows/gradle.yml/badge.svg)](https://github.com/AY2627S1-CS2103-F10-2/tp/actions/workflows/gradle.yml)
[![codecov](https://codecov.io/gh/AY2627S1-CS2103-F10-2/tp/branch/master/graph/badge.svg)](https://codecov.io/gh/AY2627S1-CS2103-F10-2/tp)

![Ui](images/Ui.png)

**TAssist is a desktop application for teaching assistants who manage students across multiple modules and tutorial classes.**

It is optimised for teaching assistants who prefer fast keyboard-based commands while retaining the benefits of a graphical interface.

* If you are interested in using TAssist, head over to the [_Quick Start_ section of the **User Guide**](UserGuide.html#quick-start).
* If you are interested in developing TAssist, the [**Developer Guide**](DeveloperGuide.html) is a good place to start.
